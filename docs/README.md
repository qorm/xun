## 设计哲学摘要

XUN 的所有 RFC 都应回答以下问题：

1. **最小惊讶**：是否符合现有 XUN 用户的直觉？
2. **Token 友好**：是否进一步降低体积 / LLM 生成开销？
3. **向后兼容**：现有 100% 合法的 v0.1.x 文件是否能被新解析器接受？
4. **跨语言一致**：6 个官方库是否能同步、无歧义地实现？
6. **当 100% 严格消歧**：是否会带来新的隐藏歧义？
